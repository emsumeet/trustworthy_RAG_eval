# Trustworthy RAG Evaluation

A research-oriented project investigating how retrieval quality and evidence sufficiency affect the factual reliability of Retrieval-Augmented Generation (RAG) systems.

The project focuses on controlled experiments rather than application demos. The goal is to separate retrieval failures from generation failures and study how different retrieval conditions influence answer quality.

---

## Research Question

How do retrieval quality and evidence sufficiency influence the factual reliability of answers generated by RAG systems?

---

## Current Experiment

### Experiment 01 — Effect of Retrieval Depth on RAG Reliability

The first experiment studies how changing retrieval depth affects:

- supporting-document recall
- complete evidence retrieval
- answer exact match
- token-level F1

The same dataset subset, retriever, generator, and prompt are used across conditions.

The only primary variable is retrieval depth.

---

## Dataset

This project currently uses:

**HotpotQA — distractor configuration**

Initial evaluation subset:

- Split: validation
- Total validation examples: 7,405
- Research subset: 100 questions
- Random seed: 42

HotpotQA is useful for this project because many questions require evidence from multiple supporting documents.
